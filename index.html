THE COURSE SLIDE SYSTEM

01 — Course System Architecture & Uniform Topic Styling

Brief

Create a consistent visual structure for CareerPaddy's growing course library.

Interpretation

The course system needed to maintain consistency across different topics while still allowing individual lessons to be visually distinct. I developed a shared colour and formatting structure that keeps related topics cohesive and makes the overall catalogue recognisable as CareerPaddy.

Execution

Created a consistent visual format across the courses, using colour, typography and recurring layouts to maintain cohesion across different topics within the same system.

02 — 20-Category Multi-Format Core System

Brief

Create a visual system that could accommodate CareerPaddy's different course categories.

Interpretation

Each category needed to feel distinct without breaking away from the wider CareerPaddy identity. I developed specialised colour palettes and visual formats that reflect the character of each category while maintaining a consistent system.

Execution

Built the core system across 20 categories, assigning each category its own colour treatment and customised visual format while maintaining a common design language across the full course library.

EDUCATIONAL & PRODUCT INTEGRITY

01 — Engine Oil Education

Brief

Show how skipping regular oil changes can damage an engine.

Interpretation

Show the negative outcome of neglected oil changes alongside the positive outcome of proper maintenance, using a single image without making the composition feel crowded.

Execution

Split the engine down the middle, with one side rusted and damaged and the other fresh and properly oiled. A grid pattern was added to the background to create depth instead of relying on a flat backdrop.
